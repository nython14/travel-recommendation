# TravelMate — Travel Recommendation

A responsive travel recommendation website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — Home, About Us, Contact Us, and navigation/search interface.
- `travel_recommendation.css` — responsive styling.
- `travel_recommendation.js` — search behavior and contact form handling.
- `travel_recommendation_api.json` — beach, temple, and country recommendations.

## Run locally
Open `index.html` in a browser. For best results, run a local static server because the JavaScript fetches the JSON data file.

## Publish with GitHub Pages
1. Push all project files to the `main` branch of your public repository.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before submitting
- Replace `ADD_YOUR_GITHUB_PAGES_URL_HERE` in the meta tag in `index.html` with your live Pages URL.
- Replace `YOUR_EMAIL@example.com` in `travel_recommendation.js` with an email address you control. The contact form opens the visitor's email application; GitHub Pages alone cannot send email from a server.
- Test searches for `beach`, `temple`, and `country`, and capture screenshots of the results for your assignment.
